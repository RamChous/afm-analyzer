# Inspectra

Система анализа видеозаписей обысков. Сотрудник АФМ загружает видео,
система прогоняет его через ML-пайплайн (детекция людей, проверка камеры,
транскрипция, диаризация по говорящим, проверка по утверждённому алгоритму
обыска через локальную LLM) и показывает результат на закрытом
веб-интерфейсе — без обращения к каким-либо внешним API.

## 0. Конфиденциальность

- Видео, транскрипты и результаты анализа остаются **только** в `uploads/`
  и `inspectra.db` на этой машине. Ничего не отправляется во внешние
  сервисы — ни видео, ни текст. LLM-анализ идёт через **локальный** Ollama,
  не через облачный API.
- `uploads/`, `inspectra.db`, `.env` уже в `.gitignore` — не коммитьте их.
- Если разворачиваете на сервере, доступном из общей сети, закройте порт
  8000 файрволом для всех, кроме внутренней сети АФМ — на уровне FastAPI
  авторизации по IP нет.

## 1. Если что-то уже было установлено — чистим окружение

```bash
# деактивировать текущее venv, если активно
deactivate 2>/dev/null

# удалить старое окружение и кэши
rm -rf .venv venv __pycache__ */__pycache__ */*/__pycache__
find . -name "*.pyc" -delete

# (опционально) если стояли пакеты глобально и мешают — посмотреть что есть
pip list
```

## 2. Создать новое виртуальное окружение

```bash
python3 -m venv .venv

# Linux / macOS
source .venv/bin/activate

# Windows (PowerShell)
.venv\Scripts\Activate.ps1
```

## 3. Установить зависимости

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

Если на Linux нет системного `ffmpeg`, поставьте его пакетом ОС (нужен для
извлечения аудио из видео):

```bash
sudo apt install ffmpeg   # Debian/Ubuntu
```

## 4. Настроить `.env`

```bash
cp .env.example .env
```

Откройте `.env` и заполните:

- `HF_TOKEN` — токен Hugging Face с доступом к модели диаризации
  (`pyannote/speaker-diarization-community-1`). Получить на
  https://huggingface.co/settings/tokens
- `LLM_MODEL` — имя модели в Ollama (по умолчанию `qwen3:14b`)
- остальные переменные можно оставить по умолчанию

## 5. Поднять локальную LLM (Ollama)

```bash
ollama serve
ollama pull qwen3:14b
```

## 6. Запустить сайт

```bash
python run.py
```

Откроется на `http://localhost:8000` (и `http://<ip-машины>:8000` для
доступа из локальной сети АФМ).

Тестовые учётные записи (создаются автоматически при первом запуске,
если `inspectra.db` пуст или отсутствует):

| Логин    | Пароль      | Роль          |
|----------|-------------|---------------|
| admin    | admin123    | admin         |
| asel     | asel123     | investigator  |
| daulet   | daulet123   | investigator  |

Самостоятельной регистрации в системе нет и не предполагается — учётные
записи сотрудников создаются заранее администратором напрямую в БД
(см. `web/database.py:init_db`, где сейчас лежат тестовые данные).

## Структура проекта

```
config/procedures/search_procedures.txt   правила обыска 
config/prompts/                           черновой промпт для справки
src/                                       ML-часть 
  models/        датаклассы (Rule, Violation, AnalysisResult, ...)
  speech/        транскрипция (Whisper) + диаризация (pyannote)
  video/         YOLO детекция людей, обнаружение перекрытия камеры, таймлайн
  llm/           оркестратор LLM-анализа нарушений (Ollama)
  reports/       экспорт в Excel / JSON
web/                                       веб-часть — сайт
  main.py        точка входа FastAPI
  pipeline.py     связывает src/ в один прогон для одного видео
  jobs.py         пул процессов — обработка видео не блокирует сайт
  auth.py        сессии, проверка пароля
  models.py      таблицы БД (User, Case, Analysis)
  i18n.py        переводы RU/KK/EN
  routes/        роуты (auth, dashboard, cases, analysis, settings)
  templates/     HTML (Jinja2)
  static/        css/js
run.py                                     запуск сайта
requirements.txt
.env.example
```

## Несколько сотрудников одновременно

Видео обрабатываются в отдельных процессах (`web/jobs.py`,
`ProcessPoolExecutor`), не в основном потоке сайта — поэтому сайт не
блокируется во время анализа, и другие сотрудники могут параллельно
заходить, смотреть прошлые дела и загружать свои видео. Количество
одновременных обработок ограничено `PIPELINE_MAX_WORKERS` в `.env`
(по умолчанию 2) — поднимайте только если на машине достаточно RAM/CPU,
так как каждый прогон держит в памяти Whisper + pyannote + YOLO.
